Recommendation Pipeline

🧠 Content-Based

Atlas Vector Search tìm phim gần nhất với user profile embedding (trung bình có trọng số của các phim đã xem). Boost theo Genre Affinity.

👥 Collaborative

Tìm users tương đồng (cosine similarity trên embedding), lấy các phim họ đã click/mua/lưu mà user hiện tại chưa xem. Weight × user similarity.

🔀 Hybrid

Kết hợp content + collaborative theo tỉ lệ. Áp dụng MMR reranking để cân bằng relevance & diversity.

Các kỹ thuật ML nổi bật

📐 Maximal Marginal Relevance (MMR)

Reranking để chống hiện tượng filter bubble — các kết quả quá giống nhau.

score = λ · sim(q, dᵢ) − (1−λ) · max sim(dᵢ, dⱼ)
// λ=0.7 trong Hybrid rec

🎭 Genre / Tag Affinity Boosting

Phân tích lịch sử tương tác → tính điểm yêu thích cho từng thể loại → boost score của phim thuộc thể loại ưa thích.

affinity[genre] += weightedScore
boost = 1 + strength × affinity_norm

📉 Time Decay

Tương tác cũ có ảnh hưởng ít hơn — sở thích của user thay đổi theo thời gian.

score_decayed = score × e−λ·days
// λ = 0.1

🎲 Exploration Replace

5% slot trong mỗi danh sách gợi ý được thay bằng item ngẫu nhiên — giúp khám phá nội dung mới, tránh local optima cho user profile.

User Profile & Embedding Update

📊 User Profile (Feature Store)

Mỗi user có một 1536-dim embedding lưu trong collection user_profiles, được cập nhật sau mỗi positive interaction:

new_emb = (prev_emb × prev_w + item_emb × w)
           ÷ (prev_w + w)

Weighted average — phim có tương tác mạnh hơn ảnh hưởng nhiều hơn

🧮 Vector Search (Atlas)

Content-Based rec dùng profile embedding làm query vector cho Atlas Vector Search (cosine similarity):

$vectorSearch: {
  index: "items_embedding_vector_index",
  queryVector: user_profile_emb,
  numCandidates: 150,
  limit: 20
}

🛡️ Guards & Fallbacks

Negative signals (weight ≤ 0) không cập nhật profile — chỉ ghi vào interactions để dùng trong filtering layer. Cold start → fallback về popular items. Timeout → circuit breaker trả về cache hoặc popular.

Điểm nổi bật kỹ thuật

⚡ Async End-to-End

FastAPI + Motor + Redis asyncio — toàn bộ stack non-blocking. Recommendations fetch 4 loại song song với asyncio.gather.

🔒 Event Sourcing

Interactions ghi vào Redis Stream trước khi xử lý. Worker consumer group đảm bảo at-least-once, failed events lưu vào failed_interaction_events.

🌡️ Circuit Breaker

Mỗi DB call wrap trong with_timeout(). Khi vector search chậm → fallback popular items. Cache hit → skip DB hoàn toàn.

🔁 Feedback Loop

Positive signals cập nhật user embedding. Negative signals (dismiss, watchlist_remove) ảnh hưởng filtering nhưng không làm hỏng profile.

📍 Attribution

rec_click mang metadata {recType} — biết click đến từ hàng gợi ý nào (hybrid/content/collab/trending) để đánh giá chất lượng từng model.

🆔 Flexible ID Resolver

Backend nhận 3 định dạng ID: ObjectId, movieId (MovieLens int), tt0803093 (OMDB). Tự động resolve sang ObjectId.
